# 🌱 HabitFlow — Habit Tracker

A fully-featured habit tracker built with Python & Streamlit.
White + green theme. Daily, Weekly, Monthly tracking.

## Setup

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features
- ✅ Daily / Weekly / Monthly habit tracking
- 📊 Analytics with charts and trends
- 📅 Calendar heatmap view
- 🏆 Achievements & badge system
- 📓 Daily journal with mood tracking
- ⚙️ Edit / Archive / Delete habits
- 🔥 Streak tracking & leaderboard
- 🎯 Completion rate per habit
- 🏷️ Tags, categories, priorities
- 💾 Persistent JSON storage (local)

## Data
All data is saved to `habits_data.json` in the same folder.
